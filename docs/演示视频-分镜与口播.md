## 一、这条视频要让评委在 2 分钟里确信三件事

| 评审的疑问 | 视频用哪一镜回答 | 为什么这镜能说服人 |
| --- | --- | --- |
| **这东西是什么？** | §2 镜 1（桌宠出场 → 日报一瞥 → 要不我先啃一口） | 第一眼是桌宠（赛道 = 陪伴），第二眼是**真实数字**（信任） |
| **凭什么信它？** | §2 镜 3（点出处 → 新标签打开知乎原回答） | **画面里真的打开了知乎页面**，不是截图不是摘要 |

> ⚠️ **最容易被忽略的一镜是 3**。很多同类视频只拍产品自己的界面 → 评审无从验证「真不真」。

## 二、轨道 A · 提交视频分镜（**2 分 00 秒**）

> **录制环境**：1920×1080 · 浏览器 F11 全屏 · 缩放 100% · **DPI 100%**（否则鼠标点不中）· 关掉全部扩展。
> **录的是正式域名** `https://pekropd3uupx.aiworks.site` —— **不要录 localhost**（评审无法验证，而且正式域名才是评委要访问的那一个）。
> **字幕必须自带关键信息**（评审可能静音看）→ **旁白配字幕 + 屏幕自带文字**，两者叠加。

### 镜 1 · 0:00 — 0:14　开场：桌宠先出场 → 日报紧跟 → 要不我先啃一口

> 这一镜是 P1 §2.1 的**三拍压成一镜**（原 0:00 / 0:05 / 0:10）—— **三拍一句都不能少**，少一拍就少一句台词。

| 项 | 内容 |
| --- | --- |
| **画面** | ① 首屏《从心日报》头版铺满 → **滚到工作台**，桌宠（`idle`）趴右下角，屏幕左侧摊着**真实收藏条目**（标题 + 知乎链接）<br>② **滚回页面顶部**，《从心日报》头版铺满<br>③ **滚回工作台**，桌宠转头（`greet`） |
| **屏幕上的字** | 刊名「从心日报」· 副题「知乎真实收藏 · 每日一印」·「第 N 期 · 当天日期」·「今日索引　你收藏 / 读过的 9 条」· 每条带作者 / 日期 / 类型 / 域名 |

| **旁白** | 「这是从心。一个趴在你桌面上的桌宠 —— 它接的是知乎开放平台的真实数据，屏幕上这一屏，就是一次真实运行的结果。」 |

> 别按直觉改成「日报先出场」—— 赛道是陪伴，第一眼必须是桌宠。

## 三、旁白的口径红线（**这份稿子最容易翻车的地方**）

> 规则来自 D38「观点是否相反数据层给不出，文案不许假装有」+ D76「你收藏过的是 over-claim」。
> **桌宠气泡不受这条管**（14 句台词已拍板），**旁白是你写的，必须守**。

| ❌ 不能说 | ✅ 改成 | 为什么 |
| --- | --- | --- |
| 这是**你的**收藏 / 接入**你的**知乎收藏 | 这是**我们接了知乎账号后**读到的真实收藏 | `/api/behavior/favorites` 用**服务端自己的密钥**取数，**没有用户绑定流** → 「你的」在技术上不成立（D76 已据此改了项目说明） |
| 两条**观点相反**的回答 / **正反**对照 | **同一个问题下的两条回答** / 回答 ① 与 ② | 上游回答对象只有 4 个字段，**没有作者也没有立场** → 分不出正反 |
| 它**替你总结**了这些内容 | 它**嚼出**了这些卡片 | 「嚼」是产品设定的动作；「总结」容易被听成模型生成 |
| 你的收藏里有 **200 篇 PDF**（创作原话） | 不提这句 | 那是**账号本人**写在创作里的原话，且是上游摘要（会被截断），不在台词目录里 |
| **6 步方案 / 4 条出处**（念死数字） | 每一步都标着依据 / 若干条真实出处 | 上游实时拉，**每次条数可能不同** |
| 它保证 / 一定 / 精准 | 它**判断适不适合你**，不替你选 | `verdict` 是 `applicable` / `partially_applicable`，不是保证 |

**另外两条**：
- **别把「服务能用」说成「每个人都能用」** —— 现在**没接 OAuth**，读到的是**项目方账号**的数据。这是事实，不丢人，说清楚反而更可信。
- **别吹没验过的东西**（比如「本地部署」「离线可用」）—— 视频里每句话都可能被评审当场点开验。

## 四、录制前必做清单（**按顺序做，别跳**）

1. **【隐私】先看一遍那 9 条收藏**
   正式域名读的是**项目方账号**的真实收藏，而**视频是公开提交给评审的**。
   → 打开收藏列表逐条扫，**有不想公开的内容就换账号或改用别的素材**。这一步不能省。

2. **【复现】用正式域名跑一遍全流程，提前 5 分钟问一次那个问题**
   `POST /api/advice` 有 **5 分钟缓存** → 提前问一次「工作压力大到睡不着怎么办」，
   录制时再问**同一个问题** → **秒出**，不用等 13—20 秒，**也不会因为上游抖了当场翻车**。
   （要拍"等待"过程的话：**另录一遍未预热的**，后期把「等待 3 秒 + 结果」剪在一起 —— **别加速，别伪造**。）

3. **【限流】正式域名有 429 限流，每刷必撞**（D75 结论 3：平台强制 `private, no-store`，缓存不生效）
   → 先完整跑一遍**预热**，录制时**一段一段录**（每个镜头单独录 2—3 条），
   **不要一次录 2 分钟再祈祷不塌**。选每镜最干净的一条。

4. **【登录】确认浏览器已登录知乎** —— 否则镜 3 / 镜 6 的新标签会打开登录页。

5. **【环境】** 1920×1080 · F11 · 缩放 100% · DPI 100% · 关扩展 · 关通知 · 关自动播放。

6. **【对稿】** 打开这一页 + `docs/演示视频-口播稿.md`，**照着念一遍**；哪句念不顺，当场改稿（**改稿要同步改这里和口播稿两处**）。

7. **【导片】** H.264 · 1920×1080 · 8—12 Mbps · **文件 < 50MB**（太大就降到 6 Mbps 或 1080p）。

## 五、轨道 B · 决赛现场 5 分钟的加长旁白

> 画面基本复用轨道 A，**多出来的 3 分钟**靠**加拍**三镜 + 现场口播补齐。决赛是**现场演示**，有你可以临场说话。

| 加拍镜 | 画面 | 现场口播（你念，不进视频字幕） |
| --- | --- | --- |
| **X1 · 语气切换**（20 秒） | 顶栏切「活泼」语气 → 桌宠同一句台词换说法说出 | 「它的语气可以切 —— 只换说法，**事实、数字、依据一个字都不改**。」 |
| **X2 · 边界态**（40 秒） | 用一个**搜不到 / 对不上出处**的问题 → 结果区显示「知乎上暂时没搜到跟这个问题相关的内容」 | 「这是它找不到的时候 —— 它会**告诉你它找不到**，不会给你一个查无出处的答案。」 |
| **X3 · 落版 & 正式链接**（20 秒） | 落版 + 正式链接 | 「评委现在就可以打开这个地址，自己点一遍。」 |

**现场要准备的三件事**
- **提前问一遍同一个问题**（缓存预热）→ 现场「问它」**秒出**。
- **「问它」冷启动 10 秒起、上游慢时更久** → 现场**先问一遍**再上台，别在台上干等。
- **一份「问了会怎样」的兜底话术**：万一上游抽风，桌宠会说「这次没找到能对得上的。我不给你一个查无出处的答案。」—— **这句是加分项不是事故**，照念，别救场。
