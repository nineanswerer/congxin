## 3. 试过但没成的（**最重要，别省**）

- **尝试**：用 `run_script` 里 `for` 循环等演练跑完（`waitForTimeout(5000)` × 24 次 ≈ 120 秒）。
  **结果**：`SCRIPT_TIMEOUT` —— **run_script 默认上限 30000ms**，不是 120 秒。
  **结论**：要等超过 30 秒**必须显式传 `timeout`**（1000—120000，默认 30000）。分次轮询更稳。

- **尝试**：一条命令里 `cd` + `git fetch` + `git rev-list ... 2>$null` + 多条检查。
  **结果**：被本地安全策略拦（`write/delete targets cannot be verified safely after a command working directory change`）。
  **结论**：带 `cd` 的复合命令里一旦有写操作（fetch / add / commit）容易触发拦；**拆成两条**跑就行。

- **尝试**：用 `node -e "require('./contracts/api.json')"` 读 JSON。
  **结果**：`ReferenceError: require is not defined` —— 根 `package.json` 是 `"type":"module"`，**`node -e` 在 ESM 包里也走 ESM**（不是 CJS）。
  **结论**：要么 `node --input-type=module -e "import fs from 'node:fs'"`，要么写脚本文件。

- **尝试**：用 `curl.exe ... | node -e` 解析额度 JSON。
  **结果**：`SyntaxError: Unexpected token '﻿'` —— **管道带了 BOM**。
  **结论**：老坑又踩了一次。额度这种要自己解析的，**直接看原始输出**，别套 node 解析。

- **尝试**：用一条正则 `keys.filter(k=>/web\/js|web\/index/.test(k))` 查部署包清单。
  **结果**：明明有 `web/js/outro.js` 却报「无」——**正则里的 `\/` 被 PowerShell 转义吃掉了**。
  **结论**：在 PowerShell 双引号里写正则，**避开 `\/`**，用 `String(x).includes('outro')` 这种朴素判断更稳。

- **尝试（同一个错犯了两次）**：用 `edit` 把 `docs/status.md` 的新条目**替换**掉原有 bullet 来"插入"新内容。
  **结果**：两次都把原有那条 bullet 整条换掉了，事后才发现、再补回来。
  **结论**：**`edit` 的 `old_string` 是锚点、要保留全文**；要插入新条目，就把锚点**原样留在 new_string 里**再往后加。
  → **本会话已犯两次，下次直接用「锚点保留式」写法。**

- **被推翻的结论**：以为「5 分钟 Demo 脚本 18 拍只有落版没实现」只是印象。
  **结果**：逐条对着 `docs/P1-三件产出.md` §二核了一遍来源列 —— **只有 4:50—5:00 那行是【提】**，其余 17 拍全是【实】。核完才敢动手。
  **结论**：别凭印象说"都实现了"，**逐行核来源列**。
