## 3. 试过但没成的（**最重要，别省**）

- **尝试**：在 `docs/status.md` 里用一次 Edit 把 B8 从"未核实"改成"已关闭"。
  **结果**：**新行插在了旧行上方，表格里出现了两个 B8**。同一次操作还改了 B7，两处一起出的问题。
  **结论**：**改表格行不要用"包含上下文的大块替换"**——先 grep 定位该 key 是否已存在（`Select-String -SimpleMatch`），再单独改那一行。
- **尝试**：在 `docs/队友对齐清单.md` 里新增"那份方案文档不能公开"的状态行。
  **结果**：**与原有那一行重复**（上一轮已犯过同类错，这次又犯）。
  **结论**：**同一类错误在两次改动里重复出现** → 说明"改表格前先 grep"这条必须变成肌肉记忆，不能靠临场判断。本项目表格一行一意，重复行会让"照抄即可"的话术出现两个版本。

- **背景（本轮之前就踩过的坑，这里再记一次）**：GitHub 仓库名不能是纯中文，会被规范化成连字符（`从心x` → `-x`）。**下一个 AI 不要再试。**详见 `docs/decisions.md` D26 与 `docs/handoffs/2026-11-17-1316-作品名与仓库改名.md`。
