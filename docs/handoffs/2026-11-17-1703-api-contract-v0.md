## 3. 试过但没成的（**最重要，别省**）

### 3.1 `zhihu-cli` 读不到用户数据 → 改走直连 HTTP

```bash
zhihu-cli me followees --limit 2 --pretty
# {"ok":false,"error":{"source":"cli","code":"AUTH_REQUIRED","message":"请登录知乎开放平台并获取 Access Secret","action_url":"https://developer.zhihu.com/profile"}}
# exit code 3
```

**结论**：CLI 侧认证不认本地 secret 文件。但 **D15 定的架构本来就是后端直连 HTTP**，所以这不影响任何事 —— 直接用 `Authorization: Bearer <Access Secret>` + `X-Request-Timestamp` 调。

### 3.2 ⚠️ **收藏类接口的真实路径，和我之前记录的完全不同**（本轮最贵的发现）

我之前记的是 `/api/v1/user/favorites/lists` 和 `/api/v1/user/favorites/recent`。**实测 404。**

```
GET /api/v1/user/favorites/lists?Offset=0&Limit=3   → 404
GET /api/v1/user/favorites/recent?Limit=3           → 404
```

真实路径（**从 zhihu-cli 二进制里 grep 字符串反查出来的**，不是猜的）：

| 用途 | 真实路径 | 必填参数 |
| --- | --- | --- |
| 近期收藏 | `/api/v1/user/collections` | — |
| 收藏夹列表 | `/api/v1/user/favlists` | — |
| 某收藏夹内容 | `/api/v1/user/favlist_contents` | `FavlistUrlToken` |

反查方法（下次要查别的接口路径也能用）：

```powershell
$bytes = [System.IO.File]::ReadAllBytes('C:\Users\steam\AppData\Local\ZhihuCLI\current\zhihu-cli.exe')
$text = [System.Text.Encoding]::ASCII.GetString($bytes)
[regex]::Matches($text, '/api/v[0-9]+/[A-Za-z0-9_/\-\.]*') | ForEach-Object { $_.Value } | Sort-Object -Unique
```

### 3.3 上游有**秒级限流**（新发现，必须写进后端设计）

连续调 `contents` 时第二次直接被拒：

```
Code=30001  Message=second limit exceeded
```

间隔 3 秒后重试即成功。**后端必须串行化 + 退避重试 + 缓存 + 去重**；前端只看到 `ZHIHU_RATE_LIMITED`（429），**不许前端自己重试风暴**。已写进契约的 `x-upstream.throttle`。

### 3.4 `ContentType` 是必填，不传直接被拒

```
GET /api/v1/user/contents?Offset=0&Limit=3
→ Code=10001  Message=ContentType is required
```

同理 `/api/v1/user/favlist_contents` 不传 `FavlistUrlToken` 也是 `Code=10001 FavlistUrlToken is required`。后端要默认补 `all`。

### 3.5 临时脚本存成 UTF-8 无 BOM → 中文路径乱码

```powershell
$f = 'C:\Users\steam\AppData\Local\Temp\validate_api.ps1'
[System.IO.File]::WriteAllText($f, [System.IO.File]::ReadAllText($f, [System.Text.Encoding]::UTF8), (New-Object System.Text.UTF8Encoding($true)))
```

不转 BOM 的后果：PS 5.1 按 ANSI 读脚本，`C:\Users\steam\Desktop\从心` 变成 `C:\Users\steam\Desktop\浠庡績` → `DirectoryNotFoundException`。

### 3.6 手滑写了垃圾 URL，被校验脚本抓出来

收藏示例里我手写了 `"url": "https://www.zhihu.com/collection/invoke"` —— 纯手滑。已改成真实的 `.../collection/931246227`。**教训：示例里的 URL 也要当数据校验，别让它混过去。**

### 3.7 `contracts/api.json` 里留了个重复 schema

一开始同时定义了 `ErrorResponse` 和 `ErrorResponseEnvelope`（内容几乎一样），前端会不知道该用哪个。已把后者降级为 `deprecated` 占位。**一个概念只能有一个 schema。**
