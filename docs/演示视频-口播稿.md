【用法】
· 每一行 = 一口气 = 一句字幕。念的时候按行断句，别自己加词。
· 桌宠气泡不用念，屏幕上自带；本文最后附一份「气泡核对表」，录完对着打勾。
· 这是旁白（解说），不是桌宠说的话。桌宠的话一个字都别改、别补。
· 配音三选一：① 你自己念（推荐，最自然） ② TTS 合成 ③ 纯字幕无解说（最省事，评审静音也能看懂）

【口气提醒 · 念的时候注意这 7 处】

1. 不说「这是你的收藏」 → 说「我们接了知乎账号后读到的真实收藏」
   （现在没接 OAuth，屏幕上读的是项目方账号的数据，别说成是观众自己的）

2. 不说「观点相反」「正反」 → 说「同一个问题下的两条回答」「回答①和②」
   （上游回答只有 4 个字段，没有作者也没有立场，数据层分不出正反）

3. 不说「它帮你总结」 → 说「嚼出」
   （"嚼" 是产品的动作；"总结" 听着像模型生成）

4. 不念死「6 步」「4 条出处」 → 说「每一步后面都标着依据」
   （上游实时拉，每次条数可能不一样）

5. 不说「保证」「一定」「精准」 → 说「判断适不适合你」「不替你选」

6. 不提「200 篇 PDF」那句创作原话
   （那是账号本人写在创作里的，且上游摘要会截断）

7. 不吹没验过的东西（本地部署、离线可用、每个人都能用）→ 评审会当场点开验
