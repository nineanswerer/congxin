## 2. 接缝怎么处理 —— 界面契约（`contracts/ui-contract.json`）

`web/index.html` 交给队友之后，风险就一句话：**我们的 JS 靠一批 id / class / data 属性取元素，他改了就静默失效。**

解法是把这批钩子**冻结成契约**，并让自检当场拦：

1. **`contracts/ui-contract.json` 是一份可读清单**：
   - `index_ids` —— **33 个 id**（`ch-pet`、`pill-profile`、`nav-detail`、`strip` …）
   - `index_classes` —— **4 个 class**（`petfigure`、`petanim`、`outro-pet`、`ch__pet-img`）
   - `index_data_attrs` —— **1 个属性**（`data-tab`）
   - `js_owned_ids` / `js_owned_classes` / `js_owned_data_attrs` —— **由我们的 JS 动态建**的元素，不在 `index.html` 里（引导卡、陪伴浮窗、「问它」面板与结果块 …）
2. **规矩只有三条**：
   - 队友**随便改** `index.html` 的结构、class、样式、素材 —— 但上表那 38 个钩子**不许删、不许改名**；
     （**反向依赖的例外见下面第 4 条**：我们造出来的元素的类名也别动）
   - **我们要新增界面元素，一律在 `web/js/` 里建 DOM**，不去改 `index.html`（用户 2026-11-24 11:1x 拍板）；
   - 确实要动某个钩子 → **先改 `contracts/ui-contract.json`，再改我们的 JS，两边一起提 PR**，不许只改一边。
3. **机器强制**：`scripts/check-contract.ps1` **第 14 项**会校验
   —— 钩子少一个就 `FAIL`（退出码 1），我们的 JS 引用了没登记的钩子就 `WARN`。
   **队友提交前必须跑一次自检**（命令见 §4）。
   已实测：把 `id="ch-pet"` 改成别的 → 自检当场 `FAIL 界面契约 ui-contract.json — index.html 里少了 id『ch-pet』`；改回来 → 恢复 `PASS 14 / WARN 0 / FAIL 0`。

4. **反过来的那条依赖（提醒用，机器不强制）**：
   我们的 JS 造出来的元素身上带 **100 多个类名**（`card` / `daily-item` / `pc__*` / `ob__*` / `ask__*` …），
   **队友改 CSS 时可以改规则内容，但别把我们要用的类名改掉** ——
   类名一改，我们造出来的东西立刻掉样式。要改名 → 先跟我们说一声，两边一起改。

5. **契约怎么维护**：我们每加一个界面钩子，跑一次
   `node scripts\extract-ui-hooks.js`（`--write` 直接回写契约文件）——
   它会扫 `web/js/*.js` 的选择器字面量，列出我们实际依赖的 id，并跟 `contracts/ui-contract.json` 对账。

## 4.1 「问它」面板：队友能改什么（2026-11-24 晚新增）

「问它」面板的 DOM 是**我们的 JS 动态建的**（不碰 `index.html`，D65），但**视觉归队友**。

> ⚠️ **这条承诺原先兑现不了**：样式原先写成内联 `style="..."`，
> **内联样式优先级高于任何 class** —— 队友在 `web/css/` 里写什么都不生效（除非 `!important`，那是坏味道）。
>
> **2026-11-24 已修**：面板样式全部改成 `var(--ask-xxx, 默认值)`，
> 并给 18 个元素补了语义 class。**现在队友在 `web/css/` 里加一行就能改，零冲突。**

| 项 | 内容 |
| --- | --- |
| **改法（推荐）** | 在 `web/css/` 里写 `:root { --ask-card-border: 2px solid #3b82f6; }` —— **不用碰我们的 JS，不用 `!important`** |
| **完整简写型变量（4 个）** | 值**必须写全「宽度 样式 颜色」**：`--ask-input-border`（输入框边框）`--ask-card-border`（答案卡边框）`--ask-src-border`（出处条边框）`--ask-step-line`（步骤分隔线，是 `border-top`） |
| **单值型变量（7 个）** | `--ask-gap` `--ask-margin` `--ask-radius` `--ask-pad` `--ask-input-radius` `--ask-src-radius` `--ask-muted` |
| **语义 class（18 个）** | `ask__head` `ask__bar` `ask__examples` `ask__result` `ask__plan` `ask__step` `ask__step-no` `ask__step-text` `ask__card` `ask__card-head` `ask__summary` `ask__verdict` `ask__caveat` `ask__sources` `ask__sources-title` `ask__src` `ask__src-title` `ask__src-meta` |
| **默认值在哪** | `web/js/app.js` 的 `ASK_STYLE`（每个 `var()` 的第二个参数）—— **没有样式表也能正常显示**，不会白板 |
| **能不能改名** | ❌ 不能。18 个 class 登记在 `contracts/ui-contract.json` 的 `js_owned_classes` 里，改名要两边一起提 PR |
| **文案归谁** | 面板里的**文字**（标题「问它一件事」、占位符、示例问题、按钮文字）是我们的，不在变量里 —— 队友要改文案 → 在群里提需求 |

> ⚠️ **踩过的坑：简写型变量不能只写一半。**
> `--ask-card-border: #3b82f6`（只给颜色）会让整条边框**直接消失**（宽度归 0、颜色变黑）——
> 因为 `border: #3b82f6` 不是合法的 border 值，浏览器会把这条声明判为无效。
> 正确写法：`--ask-card-border: 2px solid #3b82f6`。
>
> **为什么不给「只改颜色」的口子**：内联样式把 border 的**宽度、样式、颜色一起锁死**了，
> 队友想改宽度，写 `.ask__card { border-width: 2px }` **也压不过内联** ——
> 所以宽度只能靠变量给，而变量塞在简写里，就得给完整简写。
>
> **实测（2026-11-24 19:5x，浏览器里跑过）**：11 个变量逐个覆盖，全部生效；
> 卡片 `3px dashed 蓝`、步骤线 `2px solid 绿`、出处条 `7px double 紫`、输入框 `5px solid 红` 均正确渲染。

> **边界不变**：我们不碰 `web/css/`，他不碰 `web/js/`。
> 队友在 `web/css/` 加一个新文件（如 `web/css/ask-panel.css`）时，记得在 `web/index.html` 里 link 一下 —— **那一行在队友地盘，我们不动**。
