## 决策 1 · 换不换方向？

| | |
| --- | --- |
| **推荐** | **换**到「认·清」认知地形 |
| **一句话理由** | 它比"资料→卡片"更有想象力，且逐字咬合官方给"问题发现"写的能力定位原文——**"观点对照"** |

## 决策 2 · 3D 做到什么程度？

| | |
| --- | --- |
| **推荐** | **2.5D 分层认知地图**（SVG + CSS `perspective`，已在 D11 路线内）+ **断层特写用真 3D 推镜**（Three.js 只用在这一处，2—3 人时） |
| **一句话理由** | 动的是渲染层不是信息层，但把成本从 12—18 人时压到 3—5，同时解决"评审 3 分钟看懂"和"手机能用"两个硬问题 |
| **备选与代价** | 全 3D 自由漫游 → +8—13 人时；刘看山要么自建模型 20—30 人时、要么 billboard 露馅；评审进自由漫游**可能走丢**，直接伤完成度 25% |
| **✅ 底线（须确认）** | ① 允许用"**推近 + 视差**"替代自由漫游；② **断层那段的真 3D 推镜必须保留**（这是"3D 记忆点"唯一的兑现方式，别和漫游一起砍）；③ 技术栈允许 **React + Vite + TS**（2.5D 走 SVG/CSS，不引 Three.js 引擎） |

## 决策 3 · 行为对照做多深？

| | |
| --- | --- |
| **推荐** | **收藏 + 关注 + 创作 三个信号** |
| **一句话理由** | 这三样正好覆盖"做的你"三层，官方能力清单里全都有（`me favorites` / `me followees` / `me contents`），开发期用 Access Secret 读自己账号就能验证，不用等 OAuth |
| **备选与代价** | 先只做收藏 → 断层只剩一条轴，说服力弱；"创作的论证结构"是区分度最高的一条，砍掉可惜 |
| **✅ 底线（须确认）** | **首版必须能产出至少 2 个独立的行为信号** —— 断层要两块地形才能对比，只有一个信号就退化成"自述 vs 自述"，产品塌回普通 MBTI |
