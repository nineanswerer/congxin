## 本目录内容与本项目的处理

| 文件 | 原始素材 | 处理 |
| --- | --- | --- |
| `idle.webp` | 待机（100 帧） | 160×160，10fps，有损 WebP q78 |
| `thinking.webp` | 电波：坐着看笔记本电脑、头顶亮起灯泡（120 帧） | 同上 |
| `cheer.webp` | 弥撒（60 帧） | 同上 |
| `greet.webp` | 打打滚 / 挥手（80 帧） | 同上 |
| `sleep.webp` | 呆毛 / Zzz 睡觉气泡（100 帧） | 同上 |
| `play.webp` | 运球 / 踢足球（80 帧） | 同上 |
| `three-view-1..3.webp` | 刘看山三视图（正面 / 侧面 / 背面） | 800px 宽静态图，用于展示页与设计底稿 |

**转换工具链**：ffmpeg 8.1.1（`libwebp`）。原始 6 个 GIF 合计 **5692 KB**，转换后 6 个动画合计 **915 KB**，整目录 **942 KB**（约为原始的 1/6）。

**转换命令**（可复现）：

```bash
ffmpeg -i <原始.gif> -vf "fps=10,scale=160:160:flags=lanczos" \
  -c:v libwebp -lossless 0 -quality 78 -loop 0 -an <输出.webp>
```

## 使用约定

1. 素材以**状态动画**形式使用，随应用状态切换，不做形变、不做换色、不做二次创作。
2. 作品内、计划书、演示视频中都要**注明素材来源为知乎官方黑客松开放素材**。
3. 仓库根目录 `README` 与产品说明计划书的"素材与授权"一节要同步本说明。
4. 若最终决定不使用刘看山 IP，本目录可整体移除，不影响功能实现——所有状态切换都应支持"无素材时降级为一个静态占位"。

## 官方尚未覆盖的状态（本项目需自建）

素材包只提供 6 个**待机与情绪**动作，没有覆盖本项目的核心交互瞬间：

| 需要的交互 | 官方素材 | 本项目的处理方式 |
| --- | --- | --- |
| **吞咽资料** | 无 | CSS/Framer Motion 过渡：文件图标被吸入 + 角色轻微缩放，不新增角色美术 |
| **吐出卡片** | 无 | 卡片从角色位置飞出的位移动画 |
| **失败 / 额度耗尽** | 无 | 复用 `idle` 或 `sleep` + 明确的文字提示气泡，不伪造成功状态 |

保持"官方素材负责生命感、自建动画负责核心瞬间"的分工，避免为补缺口去做像素级自绘。
