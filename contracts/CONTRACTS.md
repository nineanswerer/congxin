# 契约层 — 不可变事实

> 这份文件回答一个问题：**什么东西改了会让另一个人的环境静默出错？**
> 机器可读版本在 [`contracts/contract.json`](contract.json)，`scripts/check-contract.ps1` 按它自检。
> **两份文件冲突时以 `contract.json` 为准，并立刻修正本文件。**

## 变更规则

1. 本目录**只增不改**。事实变了就写一条新的 ADR 说明"旧事实作废"，不要原地改写历史。
2. 任何改动必须同时更新 `contract.json` 和本文件，且在同一次提交里。
3. 改完跑 `powershell -ExecutionPolicy Bypass -File scripts/check-contract.ps1`，FAIL 就不能提交。
4. 涉及赛程、额度、合规红线的改动，**必须两个人都知道**——改完在群里说一句。

## 不可变事实（人读）

### 时间

- **12-04 23:59** 报名与组队截止。
- **12-05 10:00** 提交窗口开启；同刻线上开幕式 + API 讲解 + 技术专家 1V1。
- **12-07 10:00** 组队与提交截止，**此后不可改任何文件**（冻结点）。
- **12-11** 初审结果，前 15 进决赛。
- **12-19** 深圳决赛路演（5 分钟 Demo + 3 分钟 Q&A）；人气奖窗口同日结束。
- 决赛具体场地**官方未公布**，预计随 12-11 入围通知给出。

### 额度

账号完成**实名认证**后实测每日额度：

| 能力 | 次数/天 | 说明 |
| --- | --- | --- |
| 全网搜索 / 知乎搜索 | 5000 | 兜底检索 |
| 知乎热榜 | 100 | **首版不做** |
| 直答 | 100 | 只做兜底与快速解释 |
| **问题发现**（推荐问题 + 回答摘要共用） | **100** | **主路径** |
| 小工具（PDF 解析 / PPT） | 10 | PDF 解析改前端本地做，见下 |
| 知识库 / 创作能力 | 500 | 备用 |
| 知乎用户数据 | 10000 | OAuth 后可用 |

> 额度取决于**账号是否实名认证**，与是否参赛、是否领 800 美元 Token 无关。
> 800 美元是**看山工作台的模型算力**，不能用于调用开放平台接口。
> **设计一律按上表取值**，不按任何宣传口径取值。

### 技术底座

前端 + Node 单进程，**零数据库、零中间件**，会话存进程内 Map。
**理由**：官方 FAQ 明确"前端+Node后端且不含数据库写入的全栈项目"可用知乎 AI Works 部署；平台暂不支持独立数据库托管。

### 合规红线

1. Access Secret / App Key / OAuth Token **不得出现在源码、前端响应、日志、截图、视频**。
2. 刘看山 IP **仅本届比赛期间可用**，赛后禁商用；素材缺失时状态机降级为静态占位。
3. 接口失败、额度耗尽、空数据**必须给真实提示**，**绝不返回伪造兜底数据**。
4. 禁止批量、高频、无意义调用，禁止刷屏与重复投稿。
5. 不得使用任何已公开发布或已获奖项目的代码与成品。

## 为什么要有这一层

两个 AI 平台 = 两个互不相通的记忆体。Git 只记录"改成了什么"，
不记录"为什么这么改"和"试过什么失败了"。契约层把**跨环境会静默出错的东西**
显式写死，让换平台、换人、换机器之后不用靠读代码考古来猜。
