## 4. 工作期间的硬约束

- 密钥（Access Secret / App Key / OAuth Token）**不写进任何文件、不打印到终端输出、不提交**

- 改动前先在 `docs/decisions.md` 找有没有相关决策；**有冲突就提出来，不要默默按自己的理解写**
- 涉及对外可见或不可逆的动作（发布部署、联系他人、提交资料、改报名信息）→ **先问，不自己动**
